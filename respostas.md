1. O que é uma interface?

Uma interface é como um contrato que define quais métodos uma classe deve ter. Ela determina o que a classe precisa fazer, mas não como fazer.

2. Qual a diferença entre classe abstrata e interface?

A classe abstrata pode ter métodos prontos e métodos que precisam ser implementados. Já a interface define métodos que as classes são obrigadas a implementar.

3. Por que interfaces ajudam no trabalho em equipe?

Porque todos os desenvolvedores seguem o mesmo padrão de código, facilitando a organização, a comunicação e a manutenção do sistema.


DESAFIO PROFISSIONAL
1. Como interfaces ajudam um novo desenvolvedor a entender o sistema mais rápido?

As interfaces mostram quais métodos cada classe precisa ter, ajudando o novo desenvolvedor a entender como o sistema funciona e qual padrão deve seguir.

2. O que acontece se ele não seguir o contrato?

Se ele não implementar todos os métodos obrigatórios da interface, o PHP apresentará um erro e o sistema não conseguirá executar corretamente.
